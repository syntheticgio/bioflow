# metaFlye (`--meta`) — implementation plan

Date: 2026-08-20.

Closes [#727](https://github.com/syntheticgio/bioflow/issues/727). Companion to
`docs/superpowers/specs/2026-08-20-metaflye-design.md` (decisions F1–F3,
requirements R1–R6).

Small by design — Flye is already installed, probed, registered, and in every
registry, so none of the six-registry work a new tool needs applies here. The
only subtlety is the genome-size handling (F1/R4).

## Spike first

- **S-1. Does the installed Flye accept `--meta` with every `mode` the registry
  offers?** `--meta --pacbio-corr` may or may not be supported. If some pairs
  are rejected, the dialog must say so rather than letting a job fail minutes
  in. Run each combination with `--help`-level validation or a tiny read set.
- **S-2. Does `--meta` change output filenames?** F3 assumes
  `assembly.fasta` / `assembly_graph.gfa` / `assembly_info.txt` are unchanged;
  confirm against a real run before relying on it.
- **S-3. Peak RSS on a real community sample** versus what the single-genome
  model would have predicted. Not used for gating (F1), but worth recording on
  the issue — it is the evidence for why no metagenome coefficient was invented.

## Ordered steps

1. **`FlyeParams.meta` + `_flye_command`.** Two tests:
   - `meta=True` → argv contains **both** `--meta` and `--<mode>`;
   - `meta=False` → argv is **exactly** what it is today.
     Write the second as a full-argv equality assertion, not a
     `"--meta" not in argv` check. It is the regression guard for every
     existing Flye run, and an exact assertion also catches a reordering or a
     dropped flag that a negative check would sail past.
2. **The registry field** (F2). A `bool` field, default off, beside `mode` —
   **not** a seventh `mode` choice. `mode` is read accuracy, `--meta` is
   assembly strategy; they are orthogonal in the tool, and folding them
   together would make them mutually exclusive in the UI and double the choice
   list.
   Help text says what it changes (uneven coverage, no single-organism
   assumption, some contiguity cost on a true isolate), not that it passes
   `--meta`.
3. **Genome size (F1/R4) — the one piece of real logic.**
   When `meta` is on and `genome_size_source == "inferred"`, drop the inferred
   value and estimate as unknown. `resource_estimator.estimate_mb` already
   returns `None` for unknown and its docstring already says callers must treat
   that as "no opinion" and proceed — so this needs no new estimator path, only
   not passing a meaningless number into the existing one.
   **Two tests, and the second is why:**
   - inferred size + `meta` → estimator receives `None`;
   - **user-supplied size + `meta` → estimator receives the user's number**
     (R5).
     A test asserting only the first passes against an implementation that
     throws away user sizes too, which silently breaks R5.
   Record why the value was dropped in facts, so a user comparing two runs'
   estimates can see it.
4. **`assembly_meta_mode` fact** (R6). Per-key `facts.<key>` merge, never a
   whole-dict merge (#606). This is what lets #728's binning card gate on
   "this is a community assembly" instead of offering to bin any assembly.
5. **Dialog check.** The assemble dialog renders from the registry, so the
   checkbox should appear for free. Verify at `http://localhost:5273`
   (worktree stack via `./ops/worktree-up.sh`), not 5173. If it does not render,
   that is a registry-to-dialog gap worth its own note.
6. **Real run.** A community sample if one is available; otherwise a normal
   long-read set with `--meta` on, to confirm the command is accepted and the
   outputs land where F3 expects. Capture S-3's numbers here.

## What this plan deliberately does not do

- **Invent a metagenome memory coefficient** (F1). Peak residency depends on
  community complexity, not on a number anyone has; a tuned
  `bytes_per_genome_base` would dress a guess as a model, and wrong-low is an
  OOM that also poisons the timing records.
- **Infer metagenome mode from the reads** (F2). Nothing in a FASTQ says
  "community", and guessing wrong degrades the assembly silently.
- **Give the output a distinct role** (F3). The contigs are a mixture, which is
  a fact about the biology, not a different artifact type — everything
  downstream works on it unchanged.
